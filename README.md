# 🚒 Fire Rescue App

**Fire Rescue App** is an Android application developed to streamline the workflow of firefighters, providing instant access to critical information and improving response efficiency.

The app demonstrates practical Java-based Android development while addressing real-world emergency service requirements.

---

## 🚀 Key Features

* **Station & Location Information**

  * Access details of fire stations and their locations

* **Fellow Firefighter Contacts**

  * Quickly contact colleagues during emergencies

* **Instant Alerts**

  * Receive notifications for incidents and urgent updates

* **Event & Vacancy Info**

  * Stay informed about upcoming training, events, and job opportunities

* **Efficient Task Management**

  * Helps firefighters organize and respond to service calls efficiently

---

## 🛠️ Tech Stack

* **Language:** Java
* **Platform:** Android
* **Key Tools:** Android Studio, Firebase (optional for notifications/alerts)
